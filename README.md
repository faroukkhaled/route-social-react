# Circle — React Social Media Project

مشروع السوشيال الخاص بتكليف Route، مبني باستخدام **React + React Router + Vite**، مع نفس التصميم المتجاوب ووظائف النسخة السابقة. كل الصفحات مكوّنات JSX وتستخدم React Hooks وContext؛ لا يعتمد عرض التطبيق على `innerHTML` أو التحكم اليدوي في الصفحة.

## التشغيل

تحتاج Node.js إصدار **22.12 أو أحدث** لتشغيل أدوات التطوير. التطبيق نفسه Frontend React يتصل بـRoute مباشرة، ولا يحتوي على Backend مخصص أو Express أو `server.mjs`.

1. فك ضغط المشروع وافتح Terminal داخل مجلد `route-social-react`.
2. نفّذ:

```bash
npm install
npm run dev
```

3. افتح العنوان الذي يظهر في Terminal، عادةً http://127.0.0.1:5173.

لا تستخدم Live Server ولا تفتح `index.html` مباشرة؛ JSX وReact يحتاجان تشغيل Vite. لو البورت مشغول سيعرض Vite بورتًا آخر. يمكنك تحديده بـ `npm run dev -- --port 5174`.

## الوظائف

- إنشاء حساب وتسجيل دخول وخروج وحماية الصفحات.
- صفحة Feed مع تحميل المزيد وفلاتر Everyone/Following وبحث داخل المنشورات المحملة.
- تفاصيل المنشور والتعليقات مع تحميل جميع الصفحات تدريجيًا.
- الملف الشخصي ومنشورات المستخدم الحالي.
- إنشاء وتعديل وحذف المنشورات والتعليقات، وإرفاق الصور واستبدالها.
- تغيير كلمة المرور وتحديث رمز الجلسة بعد التغيير.
- رفع صورة الملف الشخصي، الإعجاب ونسخ رابط المنشور.
- تأكيد قبل الحذف، التحقق من الحقول، رسائل أخطاء وتحميل وحالات فارغة.
- تصميم متجاوب للموبايل والكمبيوتر.
- وضع تجريبي محلي يدعم عمليات المنشورات والتعليقات دون إنشاء حساب أو إرسال بيانات لـRoute.

في **Username** اكتب اسم مستخدم مثل `farouk_khaled`؛ البريد الإلكتروني له خانة منفصلة. صور الـFeed الحقيقية تأتي من منشورات Route API وليست صورًا من جهازك.

## أوامر المشروع

```bash
npm run dev       # تشغيل التطوير
npm start         # نفس تشغيل التطوير
npm run build     # إنشاء ملفات الإنتاج في dist
npm run preview   # معاينة ملفات dist بعد build
npm test          # اختبارات محلية
npm run test:live # فحوص قراءة فقط للخدمة، لا تغيّر بيانات Route
```

للنشر ارفع محتويات `dist` على استضافة ملفات ثابتة بعد `npm run build`. يستخدم React Router مسارات hash، فلا يحتاج إعداد إعادة توجيه من الاستضافة. ملف ZIP يحتوي على المصدر ونسخة `dist` الجاهزة، ولا يحتوي على `node_modules`؛ استخدم `npm install` أو `npm ci` لتثبيت المكتبات من ملف القفل.

## بنية React

```text
src/main.jsx                  createRoot + HashRouter
src/App.jsx                   routes + ProtectedRoute
src/session.jsx               Context للجلسة والـAPI والإشعارات
src/usePaged.js               Hook للتحميل المتدرج ومعالجة الطلبات المتأخرة
src/components/Layout.jsx     الهيكل المشترك
src/components/PostCard.jsx   بطاقة المنشور
src/components/Editor.jsx     نماذج الإنشاء/التعديل وتأكيد الحذف
src/components/UI.jsx         مكونات النماذج والصور والحالات المشتركة
src/pages/AuthPage.jsx        Signup/Login
src/pages/FeedPage.jsx        Feed/Profile
src/pages/PostPage.jsx        تفاصيل المنشور والتعليقات
src/pages/SettingsPage.jsx    الصورة وكلمة المرور
src/api.js                    عميل Fetch مركزي
src/demo.js                   بيانات تجريبية محلية
src/forms.js                  التحقق من النص والصور
src/styles.css                التنسيق المتجاوب
```

التوكن محفوظ في `sessionStorage` لكل تبويب، وبيانات الديمو في `localStorage` تحت `circle-demo-v1`. بيانات الـAPI الحقيقي لا تُستبدل ببيانات وهمية عند فشل الطلب. الخطوط الخارجية اختيارية ويوجد بديل من خطوط النظام. أقصى حجم للصورة في الواجهة 5 MB؛ قد يفرض السيرفر شروطًا إضافية.

## التحقق وحدوده

مسارات وحقول Route مأخوذة من التوثيق الرسمي ومجموعة Postman المرتبطة به؛ راجع `docs/API.md`. الاختبارات المحلية تختبر طريقة إرسال الطلبات، multipart، انتهاء الجلسة، فشل الشبكة ودورة CRUD التجريبية. اختبارات React في المتصفح موضحة في `docs/REACT-VERIFICATION.md`.

لم تُجر عمليات إنشاء حساب أو تعديل بيانات حقيقية على Route أثناء التحويل إلى React، ولم يُسلَّم المشروع على نظام Route. فحوص الخدمة المباشرة في `docs/live-verification.json` تخص النسخة الأولى وطلبات قراءة فقط بتاريخها المسجل. اختبار الحساب الحقيقي يحتاج قيامك بتسجيل الدخول وتجربة الوظائف؛ لا ندعي اجتياز اختبار كامل ضد API بحساب حقيقي.

قبل التسليم: جرّب التسجيل والدخول، إنشاء وتعديل وحذف منشور وتعليق، صور الحساب والمنشور، تغيير كلمة المرور ثم الدخول بالجديدة، تحميل صفحات المنشورات والتعليقات، ومقاسات الموبايل. هذه العمليات تغيّر البيانات على خدمة Route.

## حل مشاكل شائعة

- صفحة فارغة مع Live Server: شغّل `npm run dev` واستخدم عنوان Vite.
- تعذر الاتصال: جرّب https://route-posts.routemisr.com/api/health أو استخدم الديمو.
- 401: سجّل الدخول مجددًا.
- فشل التسجيل أو الرفع: اتبع رسالة السيرفر، وتحقق من اسم المستخدم والبريد وقوة كلمة المرور وحجم الصورة.
- نسخ الرابط غير متاح: افتح المنشور وانسخ عنوانه من المتصفح.

المراجع: [React](https://react.dev/learn/build-a-react-app-from-scratch)، [Vite](https://vite.dev/guide/)، [Route API](https://route-posts.routemisr.com/).
